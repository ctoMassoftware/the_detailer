📋 El Problema Original

Al completar una orden y seleccionar una boleta de rifa (ej: #008), la orden mostraba siempre #003 en el recibo. El análisis reveló que id_boleta quedaba en NULL en la base de datos, indicando que el valor NO se estaba guardando correctamente.

↓
3
POST /api/rifas/asignar-boleta
Se actualiza orden 358 con id_boleta = 357
En BD: UPDATE orden SET id_boleta = 357 WHERE id_orden = 358 ✅
↓
4
🔴 CRÍTICO: PUT /api/ordenes/358
ANTES DEL FIX: Payload NO incluía id_boleta
Resultado: id_boleta = NULL ❌ (sobrescrito)
DESPUÉS DEL FIX: Payload INCLUYE id_boleta: 357
Resultado: id_boleta = 357 ✅
